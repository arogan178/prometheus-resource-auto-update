Prometheus Resource Auto-Update

A small CLI for turning Prometheus usage metrics into Kubernetes resource updates in Kustomize repositories, with dry-run reports, pull requests, review, and revert support.

What It Does

Reads Usage

Queries Prometheus or Thanos for CPU and memory usage percentiles across accessible namespaces.

Updates Kustomize

Finds matching Kustomize resource patches and updates requests and limits for Burstable QoS.

Opens PRs

Creates or updates Bitbucket pull requests, with an interactive review flow and auto-merge thresholds.

Supports Reverts

Detects previous automated resource update commits and restores pre-optimization patch versions.

Repository Layouts

The tool supports both a single kustomize mono repo and a directory containing many kustomize repositories.

Mono Repo

KUSTOMIZE_REPOS_DIR=/path/to/kustomize-repo
KUSTOMIZE_MONOREPO_NAME=my-kustomize-repo

Multiple Repos

KUSTOMIZE_REPOS_DIR=/path/to/kustomize-repos
# child directories under this path are treated as separate repos

Sizing Formula

  • CPU request: P95 CPU multiplied by CPU_REQUEST_TARGET_FACTOR
  • Memory request: P95 memory multiplied by MEMORY_REQUEST_TARGET_FACTOR
  • CPU limit: P99 CPU multiplied by CPU_LIMIT_BUFFER_FACTOR
  • Memory limit: P99 memory multiplied by MEMORY_LIMIT_BUFFER_FACTOR

Retain floors and idle workload floors reduce the risk of shrinking workloads too aggressively in one run.

Quick Start

cp .env.example .env
$EDITOR .env
python3 auto-update.py

Use dry-run mode first to generate a Markdown report before opening pull requests.

KRR Or This Tool?

KRR is a mature Kubernetes recommendation engine. This project focuses on the apply layer: mapping recommendations to Kustomize patches, opening pull requests, and supporting review and revert workflows.

A future integration could use KRR JSON output as the recommendation source while keeping this repository focused on GitOps application.
